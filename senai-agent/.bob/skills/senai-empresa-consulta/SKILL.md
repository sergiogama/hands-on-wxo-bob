Ao responder sobre o portal SENAI Para Sua Empresa:

## Fontes de informação
- Use sempre a tool `listar_solucoes` do MCP Server senai-empresa para buscar dados atualizados
- Use `detalhar_solucao` quando o usuário pedir informações completas de um serviço específico
- Referência oficial: https://www.senai.portaldaindustria.com.br/para-sua-empresa

## Categorias disponíveis
- **capacitacao**: Cursos in company, trilhas corporativas, modalidades EAD e presencial
- **consultoria**: Diagnóstico de processos, melhoria contínua, normas técnicas
- **inovacao**: Laboratórios, ensaios, projetos P&D, transferência de tecnologia

## Saída
- Responda de forma objetiva e profissional em português
- Sempre inclua o link da solução mencionada
- Se a empresa perguntar sobre inscrição, ative a skill `senai-empresa-inscricao`
