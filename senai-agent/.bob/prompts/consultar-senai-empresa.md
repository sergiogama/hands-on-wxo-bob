name: consultar-senai-empresa
description: Consulta soluções SENAI Para Sua Empresa e apresenta um resumo personalizado por área de atuação
---

Execute os seguintes passos para consultar soluções SENAI para a empresa {{NOME_EMPRESA}}:

1. Use a tool `listar_solucoes` do MCP Server senai-empresa para buscar todas as categorias
2. Para cada categoria relevante, use `detalhar_solucao` para obter informações completas
3. Apresente um resumo personalizado com:
   - Soluções mais aderentes ao perfil da empresa
   - Modalidades disponíveis (presencial, EAD, híbrido)
   - Link oficial para cada solução
4. Pergunte se o usuário deseja iniciar uma inscrição
