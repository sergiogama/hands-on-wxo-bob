Módulo 01 Visão Geral da Solução

O que é IBM Bob?

IBM Bob é um assistente de IA para desenvolvedores distribuído como aplicativo standalone que embute o VS Code — basta baixar e instalar o IBM Bob diretamente em bob.ibm.com, sem instalar o VS Code separadamente. O editor já vem integrado e oferece capacidades agentic completas: leitura de arquivos, geração de código, execução de comandos, MCP servers, hooks, skills e modos customizados.

O que é watsonx Orchestrate?

IBM watsonx Orchestrate é uma plataforma de orquestração de agentes de IA que permite criar, compor e implantar agentes inteligentes capazes de executar fluxos de trabalho complexos integrando ferramentas externas via MCP, APIs REST e toolkits nativos.

O que é IBM Cloud Code Engine?

Code Engine é uma plataforma serverless totalmente gerenciada da IBM Cloud que executa workloads em contêineres sem necessidade de gerenciar infraestrutura. Escala automaticamente de 0 a N instâncias conforme a demanda. Usaremos o Code Engine para hospedar o agente Python após o desenvolvimento.

Sobre o Agente deste Workshop

Neste workshop construímos o SenaiEmpresaAssistant — um agente especializado no portal SENAI Para Sua Empresa. O agente é capaz de:

  • Responder perguntas sobre cursos, soluções tecnológicas e serviços para empresas oferecidos pelo SENAI
  • Listar e detalhar categorias de capacitação corporativa disponíveis
  • Orientar sobre consultoria tecnológica e inovação
  • Realizar inscrições de empresas em programas SENAI via MCP Server

Fluxo do workshop

Módulo 02 Instalando e Configurando o IBM Bob

2.1 Instalação — IBM Bob

  1. Acesse bob.ibm.com e faça o download do IBM Bob para o seu sistema operacional
  2. Execute o instalador — o IBM Bob já inclui o VS Code embutido, não é necessário instalar o VS Code separadamente
  3. Ao abrir o IBM Bob pela primeira vez, o editor estará pronto para uso

2.2 Autenticação no IBM Bob

Método 1 — SSO / IBMid (recomendado):

  1. Abra o IBM Bob
  2. Clique em Sign in — o Bob abrirá bob.ibm.com/login no browser automaticamente
  3. Faça login com seu IBMid ou SSO corporativo
  4. Retorne ao IBM Bob — a autenticação será concluída automaticamente

Método 2 — API Key:

  1. Acesse https://bob.ibm.com → Account → API Keys → Create API Key
  2. Defina o Scope como Inference e copie o valor gerado
  3. No IBM Bob, abra as configurações (Ctrl+, / Cmd+,) e cole a API Key no campo IBM Bob: API Key
Atenção: Nunca compartilhe sua API Key nem a commite no repositório.

2.3 Primeira sessão com IBM Bob

  1. Abra a pasta senai-agent/ no IBM Bob (File → Open Folder)
  2. Abra o painel de chat clicando no ícone do IBM Bob na barra de navegação (ou Option+Cmd+B no Mac / Ctrl+Alt+B no Windows)
  3. No chat, use os comandos de barra para inicializar o projeto:
# No painel de chat do IBM Bob:
/init    # gera AGENTS.md e arquivos de contexto
/mode    # lista modos disponíveis
/skills  # lista skills disponíveis

# agents/senai_empresa_agent/tools.py
import os, requests
from ibm_watsonx_orchestrate.agent_builder.tools import tool

SENAI_BASE_URL = "https://www.senai.portaldaindustria.com.br"
SENAI_EMPRESA_URL = f"{SENAI_BASE_URL}/para-sua-empresa"

@tool
def listar_solucoes_senai(categoria: str = "") -> list:
    """Lista soluções e serviços disponíveis no portal SENAI Para Sua Empresa.
    Args:
        categoria: Categoria para filtrar (ex: "capacitacao", "consultoria", "inovacao").
                   Vazio = todas as categorias.
    Returns:
        Lista de dicionários com nome, categoria, descricao e url.
    """
    # Em produção, esta tool consome a API REST do portal SENAI.
    # Durante o workshop, retorna dados representativos para demonstração.
    solucoes = [
        {"nome": "Capacitação In Company", "categoria": "capacitacao",
         "descricao": "Treinamentos customizados para equipes na empresa",
         "url": f"{SENAI_EMPRESA_URL}/capacitacao-corporativa"},
        {"nome": "Consultoria em Processos Industriais", "categoria": "consultoria",
         "descricao": "Diagnóstico e melhoria de processos produtivos",
         "url": f"{SENAI_EMPRESA_URL}/consultoria"},
        {"nome": "Laboratórios e Ensaios Tecnológicos", "categoria": "inovacao",
         "descricao": "Testes e certificações para produtos industriais",
         "url": f"{SENAI_EMPRESA_URL}/laboratorios"},
        {"nome": "Projetos de Inovação e P&D", "categoria": "inovacao",
         "descricao": "Desenvolvimento conjunto de soluções tecnológicas",
         "url": f"{SENAI_EMPRESA_URL}/inovacao"},
    ]
    if categoria:
        return [s for s in solucoes if s["categoria"] == categoria]
    return solucoes

@tool
def detalhar_solucao_senai(nome_solucao: str) -> dict:
    """Retorna detalhes completos de uma solução SENAI Para Sua Empresa.
    Args:
        nome_solucao: Nome da solução (ex: "Capacitação In Company")
    Returns:
        Dicionário com nome, descricao, publico_alvo, modalidades, contato e url.
    """
    catalogo = {
        "Capacitação In Company": {
            "nome": "Capacitação In Company",
            "descricao": "Treinamentos técnicos e comportamentais desenvolvidos "
                         "sob medida para a realidade da sua empresa.",
            "publico_alvo": "Equipes industriais, operadores, supervisores e gestores",
            "modalidades": ["Presencial na empresa", "EAD", "Híbrido"],
            "contato": "https://www.senai.portaldaindustria.com.br/contato",
            "url": f"{SENAI_EMPRESA_URL}/capacitacao-corporativa",
        },
        "Consultoria em Processos Industriais": {
            "nome": "Consultoria em Processos Industriais",
            "descricao": "Diagnóstico completo de processos produtivos com "
                         "plano de ação para ganhos de eficiência e qualidade.",
            "publico_alvo": "Indústrias de manufatura, alimentos, metalurgia e afins",
            "modalidades": ["Presencial", "Remoto"],
            "contato": "https://www.senai.portaldaindustria.com.br/contato",
            "url": f"{SENAI_EMPRESA_URL}/consultoria",
        },
    }
    return catalogo.get(nome_solucao, {"erro": f"Solução '{nome_solucao}' não encontrada."})

@tool
def realizar_inscricao_empresa(
    nome_empresa: str,
    cnpj: str,
    nome_responsavel: str,
    email_responsavel: str,
    telefone: str,
    solucao_interesse: str,
    mensagem: str = "",
) -> dict:
    """Realiza a inscrição de uma empresa em uma solução do SENAI Para Sua Empresa.
    Args:
        nome_empresa: Razão social da empresa
        cnpj: CNPJ da empresa (apenas números)
        nome_responsavel: Nome completo do responsável pelo contato
        email_responsavel: E-mail corporativo do responsável
        telefone: Telefone de contato com DDD
        solucao_interesse: Nome da solução SENAI de interesse
        mensagem: Mensagem adicional ou descrição da necessidade (opcional)
    Returns:
        Dicionário com protocolo de inscrição, status e próximos passos.
    """
    # Em produção, esta tool submete um formulário POST à API do portal SENAI.
    # O MCP Server (Módulo 07) abstrai essa chamada HTTP.
    import hashlib, time
    protocolo = hashlib.md5(f"{cnpj}{time.time()}".encode()).hexdigest()[:10].upper()
    return {
        "protocolo": protocolo,
        "status": "recebido",
        "empresa": nome_empresa,
        "solucao": solucao_interesse,
        "proximos_passos": (
            "Um consultor SENAI entrará em contato em até 2 dias úteis "
            "no e-mail informado para agendar uma reunião de alinhamento."
        ),
        "contato_emergencia": "0800 0 SENAI (0800 073 624)",
    }

Módulo 07 MCP Server — SENAI Para Sua Empresa

Neste módulo criamos um MCP Server Python que expõe as tools do portal SENAI Para Sua Empresa ao IBM Bob via protocolo STDIO. O servidor abstrai as chamadas HTTP ao portal, tornando as tools diretamente acessíveis no chat do IBM Bob.

7.1 Como funciona o MCP Server SENAI

O IBM Bob inicia o servidor MCP como processo filho (STDIO). A comunicação ocorre via JSON-RPC. O servidor implementa as tools listar_solucoes, detalhar_solucao e realizar_inscricao que interagem com o portal SENAI.

IBM Bob → stdin (JSON-RPC) → MCP Server Python
          ← stdout (resultado) ← MCP Server Python
MCP Server → HTTP GET/POST → portal.senai.portaldaindustria.com.br
                   ← JSON ← API SENAI

7.2 mcp_server/senai_empresa_mcp/server.py

# mcp_server/senai_empresa_mcp/server.py
import requests
from mcp.server import Server
from mcp.server.stdio import stdio_server
from mcp import types

SENAI_BASE = "https://www.senai.portaldaindustria.com.br"

app = Server("senai-empresa-mcp")

@app.list_tools()
async def list_tools() -> list[types.Tool]:
    return [
        types.Tool(
            name="listar_solucoes",
            description="Lista soluções e serviços SENAI Para Sua Empresa",
            inputSchema={
                "type": "object",
                "properties": {
                    "categoria": {
                        "type": "string",
                        "description": "Categoria: capacitacao | consultoria | inovacao"
                    }
                },
            },
        ),
        types.Tool(
            name="detalhar_solucao",
            description="Retorna detalhes de uma solução SENAI",
            inputSchema={
                "type": "object",
                "properties": {
                    "nome_solucao": {
                        "type": "string",
                        "description": "Nome exato da solução SENAI"
                    }
                },
                "required": ["nome_solucao"],
            },
        ),
        types.Tool(
            name="realizar_inscricao",
            description="Inscreve uma empresa em um programa SENAI Para Sua Empresa",
            inputSchema={
                "type": "object",
                "properties": {
                    "nome_empresa":      {"type": "string"},
                    "cnpj":              {"type": "string"},
                    "nome_responsavel":  {"type": "string"},
                    "email_responsavel": {"type": "string"},
                    "telefone":          {"type": "string"},
                    "solucao_interesse": {"type": "string"},
                    "mensagem":          {"type": "string"},
                },
                "required": [
                    "nome_empresa", "cnpj", "nome_responsavel",
                    "email_responsavel", "telefone", "solucao_interesse"
                ],
            },
        ),
    ]

@app.call_tool()
async def call_tool(name: str, arguments: dict) -> list[types.TextContent]:
    if name == "listar_solucoes":
        categoria = arguments.get("categoria", "")
        # Chama a API do portal SENAI (simulado no workshop)
        solucoes = [
            {"nome": "Capacitação In Company", "categoria": "capacitacao"},
            {"nome": "Consultoria em Processos", "categoria": "consultoria"},
            {"nome": "Laboratórios e Ensaios",  "categoria": "inovacao"},
        ]
        resultado = [s for s in solucoes if not categoria or s["categoria"] == categoria]
        return [types.TextContent(type="text", text=str(resultado))]

    elif name == "detalhar_solucao":
        nome = arguments["nome_solucao"]
        return [types.TextContent(type="text",
            text=f"Detalhes de '{nome}': consulte {SENAI_BASE}/para-sua-empresa")]

    elif name == "realizar_inscricao":
        import hashlib, time
        protocolo = hashlib.md5(
            f"{arguments['cnpj']}{time.time()}".encode()
        ).hexdigest()[:10].upper()
        return [types.TextContent(type="text", text=(
            f"Inscrição recebida! Protocolo: {protocolo}. "
            "Um consultor SENAI entrará em contato em até 2 dias úteis."
        ))]

    raise ValueError(f"Tool desconhecida: {name}")

async def main():
    async with stdio_server() as streams:
        await app.run(*streams, app.create_initialization_options())

if __name__ == "__main__":
    import asyncio
    asyncio.run(main())

7.3 Configuração no .bob/mcp.json (projeto)

Crie .bob/mcp.json na raiz do projeto senai-agent/:

{
  "mcpServers": {
    "senai-empresa": {
      "type": "stdio",
      "command": "python",
      "args": ["-m", "mcp_server.senai_empresa_mcp.server"],
      "alwaysAllow": ["listar_solucoes", "detalhar_solucao"],
      "disabled": false
    }
  }
}
Segurança: Este arquivo é seguro para commitar — não contém credenciais. O servidor é iniciado localmente pelo IBM Bob via STDIO.

7.4 Propriedades de configuração MCP — referência

PropriedadeTipoObrig.Descrição
typestringNão"stdio" para processo local; "streamable-http" para HTTP remoto
commandstringSim (stdio)Executável a invocar (ex: python, node)
argsarrayNãoArgumentos para o comando (ex: ["-m", "meu.modulo"])
urlstringSim (http)URL completa do endpoint MCP remoto
headersobjectNãoHeaders HTTP estáticos (ex: Authorization com token de API)
alwaysAllowarrayNãoTools aprovadas automaticamente sem confirmação
disabledbooleanNãotrue para desabilitar o servidor
timeoutnumberNãoTimeout em ms (padrão: 600.000)
Atenção: A tool realizar_inscricao não está em alwaysAllow — o Bob pedirá confirmação antes de submeter dados de inscrição.

Ao gerar testes unitários Python:

## Obrigatório
- Framework: pytest (fixtures, parametrize, raises)
- Mocks: unittest.mock (patch, MagicMock, AsyncMock)
- Estrutura: Arrange / Act / Assert com comentários
- Nomenclatura: test_deve_[comportamento]_quando_[condicao]

- Caminho feliz (happy path)
- Valores None, "", [], {}

    result = listar_solucoes_senai("capacitacao")
    # Assert
    assert len(result) > 0
    assert result[0]["categoria"] == "capacitacao"

15.2 scripts/deploy.sh — script completo de deploy

#!/bin/bash
# =============================================================================
# scripts/deploy.sh
# Deploy do SENAI Empresa Assistant no IBM Cloud Code Engine
#
# COMO USAR:
#   1. Preencha todas as variáveis no arquivo .env (copie de .env.example)
#   2. Execute: bash scripts/deploy.sh
# =============================================================================

set -euo pipefail

# ─── Carregar variáveis de ambiente ──────────────────────────────────────────
if [ -f .env ]; then
  export $(grep -v '^#' .env | xargs)
else
  echo "❌ Arquivo .env não encontrado. Copie .env.example para .env e preencha."
  exit 1
fi

# ─── Validar variáveis obrigatórias ──────────────────────────────────────────
: "${IBM_CLOUD_API_KEY:?Variável IBM_CLOUD_API_KEY não definida no .env}"
: "${IBM_CLOUD_REGION:?Variável IBM_CLOUD_REGION não definida no .env}"
: "${IBM_CLOUD_RESOURCE_GROUP:?Variável IBM_CLOUD_RESOURCE_GROUP não definida}"
: "${IBM_CLOUD_REGISTRY_NAMESPACE:?Variável IBM_CLOUD_REGISTRY_NAMESPACE não definida}"
: "${CODE_ENGINE_PROJECT:?Variável CODE_ENGINE_PROJECT não definida no .env}"

# ─── Configurações derivadas ──────────────────────────────────────────────────
APP_NAME="senai-empresa-assistant"
IMAGE_TAG="${IBM_CLOUD_REGION}.icr.io/${IBM_CLOUD_REGISTRY_NAMESPACE}/${APP_NAME}:latest"

echo "==================================================="
echo " Deploy: SENAI Empresa Assistant → IBM Cloud Code Engine"
echo "==================================================="
echo " Region:    $IBM_CLOUD_REGION"
echo " Project:   $CODE_ENGINE_PROJECT"
echo " Image:     $IMAGE_TAG"
echo "==================================================="

# ─── 1. Login na IBM Cloud ────────────────────────────────────────────────────
echo "📋 Passo 1/7 — Login na IBM Cloud..."
ibmcloud login --apikey "$IBM_CLOUD_API_KEY" \
  -r "$IBM_CLOUD_REGION" -g "$IBM_CLOUD_RESOURCE_GROUP" --quiet

# ─── 2. Login no Container Registry ─────────────────────────────────────────
echo "📋 Passo 2/7 — Login no Container Registry..."
ibmcloud cr login
ibmcloud cr region-set "$IBM_CLOUD_REGION"

# ─── 3. Criar namespace do registry (se não existir) ─────────────────────────
echo "📋 Passo 3/7 — Verificando namespace do registry..."
if ! ibmcloud cr namespace-list | grep -q "$IBM_CLOUD_REGISTRY_NAMESPACE"; then
  echo "   Criando namespace: $IBM_CLOUD_REGISTRY_NAMESPACE"
  ibmcloud cr namespace-add "$IBM_CLOUD_REGISTRY_NAMESPACE"
else
  echo "   Namespace já existe: $IBM_CLOUD_REGISTRY_NAMESPACE"
fi

# ─── 4. Build e push da imagem Docker ────────────────────────────────────────
echo "📋 Passo 4/7 — Build e push da imagem Docker..."
docker build -t "$IMAGE_TAG" .
docker push "$IMAGE_TAG"
echo "   ✅ Imagem publicada: $IMAGE_TAG"

# ─── 5. Selecionar / criar projeto Code Engine ───────────────────────────────
echo "📋 Passo 5/7 — Configurando projeto Code Engine..."
if ibmcloud ce project list | grep -q "$CODE_ENGINE_PROJECT"; then
  ibmcloud ce project select --name "$CODE_ENGINE_PROJECT"
else
  ibmcloud ce project create --name "$CODE_ENGINE_PROJECT"
fi

# ─── 6. Criar secret com credenciais da aplicação ────────────────────────────
echo "📋 Passo 6/7 — Criando/atualizando secret com credenciais..."
ibmcloud ce secret delete --name senai-agent-secrets --force 2>/dev/null || true

ibmcloud ce secret create \
  --name senai-agent-secrets \
  --from-literal ORCHESTRATE_API_KEY="$ORCHESTRATE_API_KEY" \
  --from-literal ORCHESTRATE_INSTANCE_URL="$ORCHESTRATE_INSTANCE_URL"

echo "   ✅ Secret 'senai-agent-secrets' criado"

# ─── 7. Deploy / atualizar aplicação no Code Engine ──────────────────────────
echo "📋 Passo 7/7 — Deploy da aplicação no Code Engine..."

if ibmcloud ce app list | grep -q "$APP_NAME"; then
  echo "   Atualizando aplicação existente: $APP_NAME"
  ibmcloud ce app update \
    --name "$APP_NAME" \
    --image "$IMAGE_TAG" \
    --env-from-secret senai-agent-secrets \
    --min-scale 0 \
    --max-scale 5 \
    --memory 2G \
    --cpu 0.5
else
  echo "   Criando nova aplicação: $APP_NAME"
  ibmcloud ce app create \
    --name "$APP_NAME" \
    --image "$IMAGE_TAG" \
    --env-from-secret senai-agent-secrets \
    --min-scale 0 \
    --max-scale 5 \
    --memory 2G \
    --cpu 0.5 \
    --port 8080
fi

# ─── Resultado ────────────────────────────────────────────────────────────────
echo ""
echo "==================================================="
echo " ✅ Deploy concluído com sucesso!"
echo "==================================================="

APP_URL=$(ibmcloud ce app get --name "$APP_NAME" --output json | \
  python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('status',{}).get('url','N/A'))")

echo " URL da aplicação: $APP_URL"
echo ""
echo " Comandos úteis:"
echo "   ibmcloud ce app get  --name $APP_NAME"
echo "   ibmcloud ce app logs --name $APP_NAME --follow"
echo "==================================================="
